# 全局串口栏与三页布局精修设计

日期：2026-07-24
状态：方案 A 已确认
适用项目：`D:\Codes\STM32\stem-hub-host`

## 1. 目标

按用户标注图依次完成五项调整：

1. 温度仪表使用五段离散状态色，水柱高度严格对应 `0–100°C`，移除生硬水位横线。
2. 串口状态徽章和连接按钮统一尺寸、字体；增加状态圆点与文字的距离。
3. 串口栏提升到全局页签标题区，在三个页面始终可见，并释放第一页顶部空间。
4. 第三页取消最外层大容器，改成上方一张桥接卡、下方发送/接收两张独立卡。
5. 修正图表页采样标签、采样控件和清空按钮的字体、基线及留白不一致。

## 2. 温度仪表

- 量程保持 `0–100°C`。
- 液位为 `clamp(celsius / 100, 0, 1)`。
- 负数读数文字保留真实值，液位为 0；超过 100°C 时文字保留真实值，液位为 100%。
- 五段颜色保持：
  - `0–20°C` 冷色青蓝
  - `20–50°C` 正常青绿
  - `50–65°C` 偏暖琥珀
  - `65–80°C` 警告橙
  - `80–100°C` 危险红
- 当前水柱整段使用当前温区的单一主题色，而不是完整彩虹被裁切。
- 空轨道为中性背景；水柱使用轻微纵向明暗渐变。
- 删除顶部高亮横线，使用圆角液面自然结束。
- 保留现有平滑液位动画。

## 3. 全局串口栏

### 3.1 所有权

- `MainWindow` 创建并持有唯一 `SerialBar`。
- 串口栏作为 `QTabWidget` 标题区域的浮动子控件，位于页签菜单和主题切换按钮之间。
- 连接、断开、刷新信号直接由全局串口栏接入现有 Controller 流程。
- 为兼容现有调用，`console_tab.serial_bar` 指向同一个全局实例，不创建第二份控件。

### 3.2 布局

- 左侧保留三个页签。
- 最右保留昼夜主题切换按钮。
- 串口栏靠右布置在两者之间，窗口缩小时仍不覆盖页签。
- 串口栏整体高度适配标题区，不再占用第一页正文中的 64px 行。
- 第一页仅保留原 2×3 卡片网格，顶部内容自然上移。

### 3.3 控件一致性

- 状态徽章和连接按钮使用同一固定高度、同一展示字体字号、同一字面区域宽度。
- 两者宽度统一，`CONNECTED` 和 `DISCONNECT` 均不挤压。
- 状态圆点向左固定，文字留出更宽的左内边距，圆点与文字不粘连。
- 端口选择框适当压缩，但保留端口名和下拉箭头。

## 4. 第三页三卡结构

- `PassthroughPanel` 本身改为透明、无边框布局容器。
- `bridge_panel` 使用独立卡片样式，占第一排。
- `tx_panel`、`rx_panel` 使用独立卡片样式，占第二排左右两列。
- 页面外边距和三张卡片之间的间距沿用全局页面/网格 token。
- 透传功能、状态机、文本/Hex 语义、计数器和清空行为不变。

## 5. 图表工具栏文字

根因：`SAMPLE RATE` 使用未命名普通标签，`CLEAR DATA` 没有明确字体角色，二者继承全局正文字体；而工具栏标题使用展示字体、数值框使用等宽字体，导致字宽、基线和控件留白不一致。

修复：

- 为采样标签创建明确对象名和展示字体。
- 采样数值框继续使用等宽字体并设置统一高度。
- 清空按钮使用与工具栏动作一致的展示字体、字号和固定高度。
- 标签、数值框和按钮垂直居中，使用统一 token 间距。
- 不改变 `0.2–1.0 Hz` 范围、步进或默认值。

## 6. 验收

- 10/25/58/72/90°C 的液位分别与其百分比一致，颜色属于对应五段。
- 温度仪表绘制不再出现水位横线。
- 切换三个页签时串口栏始终可见且实例不变。
- 串口徽章和按钮尺寸、字号一致，圆点与文字间距明显增加。
- 第一页不再包含页内串口行，2×3 网格向上扩展。
- 第三页根容器无可见边框，仅显示三张独立卡片。
- 图表工具栏文字字体角色和控件高度一致。
- 深浅主题、固定窗口、全屏视觉矩阵全部通过。
- 全量测试和新 EXE `--fake` 启动验证通过。

## 7. 非目标

- 不改变固件协议或透传协议。
- 不改变图表采样频率逻辑。
- 不删除或重建 `env\release`。
