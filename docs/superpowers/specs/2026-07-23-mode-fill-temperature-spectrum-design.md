# 电机模式填充与温度色谱仪表设计

日期：2026-07-23
状态：已确认，待实施
适用项目：`D:\Codes\STM32\stem-hub-host`

## 1. 目标

本轮只处理控制台首页的两个视觉问题：

1. 电机模式标题框不能只改变边框和文字颜色，内部填充也必须随当前模式变化。
2. 温度仪表固定采用 `0–100°C` 量程，并使用与日/夜主题协调的多段色谱表达当前温度，替换现有单色液柱和顶部发光圆泡。

本轮不改变固件协议、电机控制命令、温度告警阈值、卡片布局或窗口尺寸。

## 2. 电机模式标题框

### 2.1 状态语义

标题框继续显示 `MODE: <状态>`，边框、状态文字、辉光和内部填充使用同一语义色族：

| 模式 | 语义 | 填充色倾向 |
|---|---|---|
| `SLEEP` | 休眠/停用 | 中性蓝灰 |
| `WAKE` | 唤醒/待命 | 暗琥珀 |
| `FWD` | 正向运行 | 主题青绿 |
| `REV` | 反向运行 | 主题青绿 |
| `BRAKE` | 制动 | 暗红 |
| `STOP` | 停止 | 暗红 |
| 无状态 | 未知/断线 | 当前中性卡片渐变 |

### 2.2 表面处理

- 填充不是整块高饱和纯色，而是将模式语义色以低透明度混入卡片底色。
- 渐变起点比终点更明显，保持现有左上到右下的材质方向。
- 深色主题使用更低亮度和较弱透明度；浅色主题使用较浅的有色底面并保证深色文字对比度。
- 边框和状态文字仍使用清晰的状态色，辉光只作用于状态文字，不扩大到整张卡片。
- 颜色计算集中在主题层，不在控件内散落硬编码色值。

## 3. 温度仪表

### 3.1 数据映射

- 仪表最小值固定为 `0°C`，最大值固定为 `100°C`。
- 仪表液位计算为 `clamp(celsius / 100, 0, 1)`。
- 负温时，文字仍显示真实负数，但液位停在 0。
- 超过 `100°C` 时，文字仍显示真实数值，但液位封顶在 100%。
- 无数据时显示 `--`，液位为 0，使用主题弱化色。

### 3.2 色谱

温谱自下而上分为五个连续区间：

| 温度区间 | 状态 | 色相 |
|---|---|---|
| `0–20°C` | 偏冷 | 青蓝 |
| `20–50°C` | 正常 | 青绿 |
| `50–65°C` | 偏暖 | 柔和琥珀 |
| `65–80°C` | 警告 | 暗橙 |
| `80–100°C` | 危险 | 克制红 |

`65°C` 和 `80°C` 继续对应现有警告与危险阈值。仪表轨道展示一层非常弱的完整温谱，使用户能读懂固定量程；已填充部分显示更清楚的相同温谱，并裁切到当前液位。这样颜色既表达绝对量程，也表达当前状态。

深色主题的色谱降低明度与饱和度，避免霓虹感；浅色主题使用更深的同色相，以保证白色卡片上的可见度。

### 3.3 动效与造型

- 保留液位从旧值平滑过渡到新值的动画，仍使用短时 `OutCubic` 缓动。
- 删除液位顶部的发光圆泡。
- 在当前液位顶部绘制一条窄的状态色高亮线作为读数指示。
- 轨道保留圆角和 `25/50/75%` 刻度，视觉中心和卡片布局不变。
- 温度数值文字使用当前温区颜色；标题仍使用次级文字色。
- 主题切换时立即重新取色，不触发一次额外液位动画。

## 4. 可访问性和一致性

- 颜色不是唯一信息来源：数值文字、液位高度和三条刻度共同表达温度。
- 深浅主题均要保证数值文字与卡片背景有足够对比。
- 失联状态不使用任何温度状态色，避免把“无数据”误认为低温。
- 电机 `BRAKE/STOP` 的安全红语义与现有按钮保持一致。

## 5. 验证标准

### 自动化

- `40°C` 映射为 `0.40`，`0°C` 为 `0.0`，`100°C` 为 `1.0`。
- 负温映射为 `0.0`，超过 100°C 映射为 `1.0`。
- 五个代表温度返回五个按色相区分的主题色。
- 深、浅主题切换后温谱 token 和状态颜色发生相应变化。
- 电机模式标题框在 `FWD`、`WAKE`、`BRAKE` 等模式下，内部像素呈现对应色相，而不是相同的通用青色表面。
- 顶部圆泡绘制被移除，仪表保留液位动画属性。

### 视觉

- 更新 16 张日/夜、固定窗口/全屏、各页面黄金截图。
- 控制台截图中，模式标题框内部填充与当前模式一致。
- 四个温度仪表在不同温度种子下能同时显示冷、正常、偏暖、警告/危险等色相。
- 深色主题不出现过亮的大面积色块。

- 不新增温度配置项或自定义阈值。
- 不改变电机状态机和命令发送逻辑。
- 不重排 2×3 首页结构。
- 不删除或重建保留的 `env\release` 打包环境。
